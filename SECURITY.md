# Security policy

Security reports are welcome through GitHub's private vulnerability reporting feature for this repository.

Please include the affected version or commit, a minimal reproduction, impact, and any suggested mitigation. Avoid filing a public issue until a fix or coordinated disclosure plan is available. You can expect acknowledgement within five business days.

Only the latest release line receives security fixes. This reference implementation must be deployed behind authentication and TLS; see the [threat model](docs/threat-model.md) for its deliberate boundaries.
