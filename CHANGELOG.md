# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). The project uses semantic versioning.

## [1.0.0] - 2026-08-08

### Added

- durable workflow execution with versioned embedded definitions
- expiring leases and deterministic command redelivery
- bounded forward and compensation retries
- atomic checksummed file snapshots with optimistic concurrency
- native HTTP API, container runtime, tests, CI, and security documentation
